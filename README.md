# 👩‍💻 Fernanda Beckman — Portfólio Pessoal

Bem-vindo(a) ao repositório do meu portfólio pessoal! Esta aplicação web foi desenvolvida para apresentar meus projetos, habilidades técnicas, trajetória profissional e formas de contato de maneira interativa e elegante.

🚀 **Live Demo:** [fernanda-beckman-portfolio.lovable.app](https://fernanda-beckman-portfolio.lovable.app)

---

## 📌 Sobre o Projeto

O portfólio serve como uma vitrine centralizada para exibir minha evolução no desenvolvimento de software e projetos práticos.

### Key Features
* 🙋‍♀️ **Sobre Mim:** Apresentação da minha trajetória, valores e objetivos na área de tecnologia.
* 💻 **Projetos em Destaque:** Vitrine interativa com links para repositórios e demonstrações ao vivo (*live demos*).
* 🛠️ **Habilidades & Tecnologias:** Exibição das principais linguagens, frameworks e ferramentas do meu *tech stack*.
* 📬 **Contato:** Seção com links diretos para minhas redes (GitHub, LinkedIn) e formulário/e-mail para contato.
* 🎨 **Design Responsivo:** Interface otimizada para dispositivos móveis e desktops, com navegação fluida e tema moderno.

---

## 🛠️ Tecnologias Utilizadas

* **Front-end:** [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) + [Javascript].
* **Build Tool:** [Vite](https://vitejs.dev/)
* **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
* **Plataforma de Desenvolvimento & Deploy:** [Lovable](https://lovable.dev/)
